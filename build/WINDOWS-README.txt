PP6 Studio — Windows 版使用说明
=================================

这是什么
--------
PowerProject V6 配置同步工作台。把 Excel 规格表解析成同步包，也可以连接数据库做探索。

这不是安装包，是便携版（免安装）：解压就能用，不写注册表，不装服务。


怎么启动
--------
1. 先解压。注意：**必须解压整个文件夹**，不能只把 PP6ImportBuilder.exe 单独拖出来。
   exe 依赖同目录下的 _internal 文件夹（里面是 Python 运行时和依赖库），
   少了它双击会弹「找不到 xxx.dll」。
2. 双击 PP6ImportBuilder.exe，会出现一个独立的应用窗口（不带地址栏、没有标签页），
   和普通桌面软件一样可以最小化、拖动、Alt+Tab 切换。


关窗口不等于退出（有托盘）
--------------------------
为了让服务常驻、下次打开是秒开，**关闭窗口只是把窗口关掉，程序还在后台运行**。
右下角托盘区会出现一个 PP6 图标。

- 想再打开窗口：双击托盘图标，或右键 →「打开主窗口」；
  也可以再双击一次 exe（会把已有窗口拉到前面，不会再开第二个）。
- **想彻底退出：右键托盘图标 →「退出 PP6 Studio」**。
  只关窗口的话，任务管理器里还能看到 PP6ImportBuilder.exe，这是设计如此。

如果所在机器上托盘建不起来（少见），程序会自动变成「关窗口就退出」，
不会留一个看不见的后台进程。


窗口是用什么做的
----------------
窗口用的是系统自带的 Edge（没装 Edge 就用 Chrome）的应用模式：
独立 profile、独立进程，所以关窗口能被准确感知。
实现上不依赖 WebView2 的 .NET 组件，也就不会出现以前那种「未响应」。

找不到 Edge / Chrome 时（极少见），程序会退回默认浏览器打开，功能完全一样。


第一次打开被 Windows 拦了怎么办
--------------------------------
因为程序没有购买代码签名证书，Windows SmartScreen 会提示
「Windows 已保护你的电脑」。

处理：点提示框里的「更多信息」→ 再点「仍要运行」。
只需要第一次，之后不再提示。

如果连「仍要运行」都没有，右键 exe → 属性 → 勾选最下面的「解除锁定」→ 确定。


系统要求
--------
- Windows 10 或 11（64 位）
- 系统自带 Edge（Win10/11 默认都有）；没有 Edge 时用 Chrome；两者都没有则改用默认浏览器
- 没装 Python 也能跑，运行时已经打包进去了


出问题了看哪里
--------------
程序运行日志（出任何问题先看这个）：

    C:\Users\<你的用户名>\.pp6kit\logs\app.log

崩溃日志（程序直接消失、闪退时看这个）：

    C:\Users\<你的用户名>\.pp6kit\logs\crash.log

日志里带毫秒时间戳和每一步的耗时，例如：

    本地服务就绪 -> http://127.0.0.1:8770/（启动后 0.31 秒）
    应用窗口已启动（Edge，托盘已就绪）-> http://127.0.0.1:8770/

正常情况下从双击到窗口出现 1~3 秒（首次运行 Windows Defender 会扫一遍，
可能到 10 秒左右，属正常）。


数据存在哪
----------
配置（数据库连接、模型 API Key、缓存的对象清单）存在：

    C:\Users\<你的用户名>\.pp6kit\

删掉这个文件夹等于恢复出厂设置。换电脑时把这个文件夹复制过去，
配置就跟着过去了（注意里面有数据库密码和 API Key，别随便外发）。

窗口用的浏览器 profile 也在同一目录下的 appwindow 文件夹，可以一起删。


哪些功能要联网
--------------
- 解析 Excel、生成同步包：**完全离线可用**，不需要网络
- 查库 / AI 生成：需要能连通目标数据库和内网网关
  不在公司内网时这两块用不了，其余功能正常


常见问题
--------
Q: 双击后什么都没有？
A: 先看托盘区（可能要展开「^」）有没有 PP6 图标。有图标说明已经起来了，
   双击图标即可打开窗口；没有的话看 app.log 最后 30 行。

Q: 关了窗口，但任务管理器里还有进程？
A: 正常。这是「托盘常驻」设计：右键托盘图标 →「退出 PP6 Studio」才真正结束。

Q: 双击闪一下就没了？
A: 大概率是只拿了 exe 没拿 _internal 文件夹。解压整个目录再试。

Q: 双击后没反应，也没窗口？
A: 手动打开浏览器访问 http://127.0.0.1:8770/ 。
   页面能打开就说明服务正常，只是窗口没能起来（日志会写原因，
   常见是这台机器没有 Edge/Chrome，或 profile 目录不可写）。

Q: 提示端口被占用？
A: 程序会自动在 8770-8789 之间找空闲端口，通常不用管。
   日志里会打印实际使用的地址。

Q: 想让窗口和以前一样直接用浏览器打开？
A: 命令行运行：PP6ImportBuilder.exe --browser
   用完想换回应用窗口：PP6ImportBuilder.exe --window
