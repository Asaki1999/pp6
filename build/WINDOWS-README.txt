PP6 Studio — Windows 版使用说明
=================================

这是什么
--------
PowerProject V6 配置同步工作台。把 Excel 规格表解析成同步包，也可以连接数据库做探索。

这不是安装包，是便携版（免安装）：解压就能用，不写注册表，不装服务。


怎么启动
--------
1. 先解压。注意：**必须解压整个文件夹**，不能只把 PP6ImportBuilder.exe 单独拖出来。
   exe 依赖同目录下的 _internal 文件夹（里面是 Python 运行时和依赖库），
   少了它双击会弹「找不到 xxx.dll」。
2. 双击 PP6ImportBuilder.exe。程序会自动打开窗口。
   如果窗口没出现，用浏览器访问 http://127.0.0.1:8770/


第一次打开被 Windows 拦了怎么办
--------------------------------
因为程序没有购买代码签名证书，Windows SmartScreen 会提示
「Windows 已保护你的电脑」。

处理：点提示框里的「更多信息」→ 再点「仍要运行」。
只需要第一次，之后不再提示。

如果连「仍要运行」都没有，右键 exe → 属性 → 勾选最下面的「解除锁定」→ 确定。


系统要求
--------
- Windows 10 或 11（64 位）
- 界面用 Edge WebView2 渲染，Win10/11 默认自带这个组件
- 万一系统缺 WebView2，程序会自动改用默认浏览器打开，功能不受影响
- 没装 Python 也能跑，运行时已经打包进去了


数据存在哪
----------
配置（数据库连接、模型 API Key、缓存的对象清单）存在：

    C:\Users\<你的用户名>\.pp6kit\

删掉这个文件夹等于恢复出厂设置。换电脑时把这个文件夹复制过去，
配置就跟着过去了（注意里面有数据库密码和 API Key，别随便外发）。


哪些功能要联网
--------------
- 解析 Excel、生成同步包：**完全离线可用**，不需要网络
- 查库 / AI 生成：需要能连通目标数据库和内网网关
  不在公司内网时这两块用不了，其余功能正常


常见问题
--------
Q: 双击闪一下就没了？
A: 大概率是只拿了 exe 没拿 _internal 文件夹。解压整个目录再试。

Q: 提示端口被占用？
A: 程序会自动在 8770-8789 之间找空闲端口，通常不用管。
   如果确实起不来，命令行运行：PP6ImportBuilder.exe --port 8790

Q: 想让同一 WiFi 下的手机也能访问？
A: 命令行运行：PP6ImportBuilder.exe --lan
   然后手机浏览器打开 http://<电脑的局域网IP>:8770/
   注意：这个服务没有密码，用完记得关掉。
