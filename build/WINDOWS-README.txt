PP6 Studio — Windows 版使用说明
=================================

这是什么
--------
PowerProject V6 配置同步工作台。把 Excel 规格表解析成同步包，也可以连接数据库做探索。

这不是安装包，是便携版（免安装）：解压就能用，不写注册表，不装服务。


怎么启动
--------
1. 先解压。注意：**必须解压整个文件夹**，不能只把 PP6ImportBuilder.exe 单独拖出来。
   exe 依赖同目录下的 _internal 文件夹（里面是 Python 运行时和依赖库），
   少了它双击会弹「找不到 xxx.dll」。
2. 双击 PP6ImportBuilder.exe。程序会自动用你的默认浏览器打开界面
   （地址是 http://127.0.0.1:8770/）。
   浏览器没弹出来也不要紧，手动在地址栏输入这个地址即可。


关于「用浏览器打开」这件事
--------------------------
界面本身就是本地网页，用浏览器打开和用应用窗口打开，功能完全一样。

这个版本默认走浏览器，是为了绕开 Windows 上 WebView2 组件的初始化问题：
部分机器（WebView2 版本不匹配、或缺 .NET 运行时）会在创建应用窗口时卡死，
表现出来就是「程序未响应」，而且看不到任何报错。

如果你确实要独立的应用窗口，命令行加参数即可：

    PP6ImportBuilder.exe --window

这时若窗口卡住，程序会在 20 秒后自动把同一地址交给浏览器兜底，
不会让你一直对着白屏。


第一次打开被 Windows 拦了怎么办
--------------------------------
因为程序没有购买代码签名证书，Windows SmartScreen 会提示
「Windows 已保护你的电脑」。

处理：点提示框里的「更多信息」→ 再点「仍要运行」。
只需要第一次，之后不再提示。

如果连「仍要运行」都没有，右键 exe → 属性 → 勾选最下面的「解除锁定」→ 确定。


系统要求
--------
- Windows 10 或 11（64 位）
- 默认需要系统有浏览器（Edge、Chrome 任一即可，Win10/11 自带 Edge）
- 没装 Python 也能跑，运行时已经打包进去了
- 用 --window 模式才需要 Edge WebView2 运行时（Win10/11 一般自带）


出问题了看哪里
--------------
程序运行日志（出任何问题先看这个）：

    C:\Users\<你的用户名>\.pp6kit\logs\app.log

崩溃日志（程序直接消失、闪退时看这个）：

    C:\Users\<你的用户名>\.pp6kit\logs\crash.log

日志里带毫秒时间戳和每一步的耗时，例如：

    本地服务就绪 -> http://127.0.0.1:8770/（启动后 0.31 秒）
    浏览器模式已启动: http://127.0.0.1:8770/

正常情况下从双击到服务就绪在 1~3 秒（首次运行 Windows Defender 会扫一遍，
可能到 10 秒左右，属正常）。


数据存在哪
----------
配置（数据库连接、模型 API Key、缓存的对象清单）存在：

    C:\Users\<你的用户名>\.pp6kit\

删掉这个文件夹等于恢复出厂设置。换电脑时把这个文件夹复制过去，
配置就跟着过去了（注意里面有数据库密码和 API Key，别随便外发）。


哪些功能要联网
--------------
- 解析 Excel、生成同步包：**完全离线可用**，不需要网络
- 查库 / AI 生成：需要能连通目标数据库和内网网关
  不在公司内网时这两块用不了，其余功能正常


常见问题
--------
Q: 双击后一直「未响应」？
A: 先确认拿到的是本说明所在版本（默认浏览器模式）。这个版本不创建窗口，
   理论上不会出现「未响应」。
   若仍异常，把 C:\Users\<用户名>\.pp6kit\logs\app.log 的最后 30 行发回来，
   日志会指明卡在哪一步。

Q: 双击闪一下就没了？
A: 大概率是只拿了 exe 没拿 _internal 文件夹。解压整个目录再试。

Q: 双击后没反应，也没弹浏览器？
A: 手动打开浏览器访问 http://127.0.0.1:8770/ 。
   页面能打开就说明服务正常，只是自动唤起浏览器被系统拦了。

Q: 提示端口被占用？
A: 程序会自动在 8770-8789 之间找空闲端口，通常不用管。
   日志里会打印实际使用的地址。

Q: 想用独立应用窗口？
A: 命令行运行：PP6ImportBuilder.exe --window
   用完想换回浏览器：PP6ImportBuilder.exe --browser
