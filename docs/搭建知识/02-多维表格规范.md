# 02 · 多维表格（列表）规范

来源：`PP6/搭建规范手册.pdf`「创建多维表格」章节 + 视频《搭建相关资料》实测。
**结论先行**：数据模板有两种展示形式（列表 / 多维表格），**目前统一采用多维表格**
（`showType="dimension"`）。我们的生成器已对齐。

---

## 1. 依赖链（比我们现有的假设多一步）

```
业务对象 ──生成表──▶ 物理表 PP_xxx ──▶ 数据集 ──▶ 数据模板(多维表格) ──▶ 挂菜单
                          ·
                     表单直接绑业务对象，不经过数据集
```

### 1.1 数据集的配置

- 入口：搭建管理 - 数据集管理 → 添加
- 填：名称、**数据集 Key**、分类、**类型**
- **数据集 Key = 物理表名去掉 `pp_` 后的部分**
- **类型建议选「物理表」，而不是直接选业务对象** ⚠️

> 这条对我们很关键：我们生成列表时 `datasetKey` 直接填的是**业务对象编码**，
> 相当于跳过了「建数据集」这一步，且类型不是「物理表」。
> 需要拿一个真实「列表 + 数据集」导出包确认服务端是否接受。

### 1.2 数据模板

- 入口：搭建管理 - 列表管理 → 创建数据模版
- 模版 key：小写 + `_` 分隔
- **唯一字段选主键**
- **绑定表单选新建表单**
- 在「模版配置」里配查询条件

---

## 2. 表格视图配置（标配）

### 2.1 基础

| 项 | 规范 |
|---|---|
| 高度 | 通常**填充容器**；个别页面自动计算高度出问题，要用公式算。详情页内的多维表格用**适应内容** |
| 网格样式 | 数字型数据多、或在线编辑频繁 → 用**网格样式** |

### 2.2 工具栏按钮

**推荐顺序**：`添加` → `视图切换` → `发起流程` → `更多`

| 按钮 | 功能 | 使用要点 |
|---|---|---|
| **添加** | 打开模板属性-拓展属性里绑定的表单作为新建页 | 新建页顶部工具按钮从外部传入，表单内部按钮失效；新增后自动关抽屉并刷新。**编辑页按钮要在表格视图设置最下方配置** |
| 视图切换 | 配置多视图时用来切换 | 配了多个视图就要加 |
| 发起流程 | 仅 1 个流程时直接发起；多个时打开抽屉选 | 可自定义或来自「流程管理」 |
| 参数配置 | 主列表用（项目/需求/评审列表） | **是自定义按钮**：开启级联 → 级联类型「在线表单」→ 选表单 |
| 自动化 | 进指定分类下配置通知规则 | **所有主列表都要配**（项目配项目、风险配风险、合同配合同）。先到「搭建管理-自动化管理」建规则引擎分类 |
| 自定义列 | 控制显示哪些列 | 来源是显示字段。显示字段的小眼睛关闭 → 不进表格但留自定义列；显示格式设「隐藏」→ 两处都不显示。**不受权限控制** |
| 导入 | — | 在「导入设置」页选**导入专用表单**；有更新业务则设「更新依据字段」；填导入说明 |
| 导出 | 导出显示字段 | 继承显示字段的显示格式；隐藏域不出现 |
| 流程管理 | 前台维护流程 | 可绑流程分类或指定流程定义 |
| 批量删除 / 批量编辑 | 按需 | |
| 高级查询 | **已废弃** | 不要再用 |

**特别注意**：
- 详情页面下方的表格工具栏按钮要用**白色按钮**，颜色选「默认」
- **自定义列、高级查询不受权限控制**，不需要加菜单资源；
  参数配置、流程管理、自动化、导入、导出、批量操作**需要权限控制**
- **按钮的资源别名不能修改**

### 2.3 导入默认值（动态参数）

场景：在项目下导入风险/问题，要把数据挂到当前打开的项目上。

- 绑定类型目前**仅支持「动态参数」**
- 动态参数从 `template.params` 取，列表布局的数据模板 / 在线表单都会注入 `objectId`
- `objectId` = 当前跳转业务对象的 id
- 例：项目问题导入时，把「隶属项目」字段值设为 `objectId`

## 3. 显示字段配置

| 项 | 规范 |
|---|---|
| **固定列** | 通常把名称字段作为固定列。要固定「缺陷名称」，必须把它**及其之前的所有列**都设为固定才生效 |
| **对齐** | 名称列**左对齐**；其余**居中**；描述/多行文本等长内容也**左对齐** |
| **宽度** | 每一列都要设。名称字段开**自适应宽度**（高分辨率下自动分配剩余宽度） |
| 显示格式 | 默认**继承绑定表单**中对应字段的显示格式。例：项目经理字段库里存人员 ID，绑定表单用了「选择器-人员」，则显示姓名；绑定表单没配 → 显示人员 ID。也可以不继承、单独设置 |

### 3.1 接口合并（功能完善中）

- 作用：项目列表含项目类型/状态/项目经理，不开要走 4 个接口，开了 1 个就返回
- 仅推荐**列表展示**场景；要用在线编辑则**不建议开**
- 配置「显示字段名」即表示开启
- **仅人员、关联数据、数据字典控件**可开；文本、日期、数字不需要

## 4. 开启级联的三种用法（很重要）

| 场景 | 级联类型 | 说明 |
|---|---|---|
| 普通对象详情（点风险名称进详情） | **在线表单** | 绑详情表单，以**编辑方式**打开，传当前行主键 |
| 流程节点审批页（点问题名称进审批） | **业务流程页面** | 选绑定的流程定义，传当前行主键 |
| 路由跳转（点项目名称进列表页） | 配路由参数 | 显示方式通常「当前页」 |

### 4.1 路由跳转参数表（手册原文）

| 参数键 | 说明 |
|---|---|
| `t` | 对象类型。顶部收藏功能会用到 |
| `i` | 当前行 ID。顶部标题需要 ID 查询 |
| `fk` | 配置在线表单的 key。顶部内容从表单接口获取 |
| `pk` | `fk` 表单数据中主键的标识 |
| `tk` | `fk` 表单数据中名称字段的标识。根据 `i` 查 `fk` 的数据，取 `tk` 属性显示在顶部标题区 |
| `a` | 跳转到指定路径，如项目团队、项目风险 |

## 5. 权限（两部分）

### 5.1 数据权限
- 在**模版属性处选择所属业务对象**
- 开启「标准对象数据权限」→ 在权限管理-数据权限处设置

### 5.2 功能权限
1. 进「搭建管理-业务对象扩展」→ 添加 → 填业务对象、新建的条件专用表单、
   选子系统、选前面挂载出来的菜单
2. 若对象下有角色（项目-团队、产品-团队），需设置**业务对象成员表**
3. 进「系统管理-菜单管理」，在项目菜单下新增
   「项目列表顶部按钮」「项目列表操作列按钮」两个目录做归类
   （**不要开启目录显示至菜单**）
4. 回到多维表格设置，把工具栏按钮、操作按钮分别添加到对应菜单目录下
5. 到「权限管理-功能权限」授权

> ⚠️ 刚加到菜单资源里的资源**是没有权限的**，必须授权后才能用。

---

## 6. 树形结构（按需）

- 配**父 ID 字段**、树形展开字段按钮
- **父 ID 字段必须在显示字段里返回**，其显示格式可设为「隐藏」，
  这样不进自定义列

---

## 7. 挂菜单

点「更多」→「添加菜单资源」，挂到对应子系统下。

菜单路径对应不同实现方式（来自运维说明）：

| 路径 | 类型 |
|---|---|
| `/f/xx` | 表单菜单 |
| `/dk/xx` | 数据模版菜单 |
| `/xxx/xxx.vue` | 硬编码菜单 |
