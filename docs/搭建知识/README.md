## 最重要的 5 条（记住这些就够日常判断）

1. **字段物理名必须小写、`_` 分隔、以 `_` 结尾**（`ba_dian_`）；
   但**自定义字典的 typeKey 不带下划线**（`对象编码_字段编码`）——两者别混。
2. **四类表单各有自己的 class 和尺寸**：新建 `pp-drawer-add`/106px/90%/按钮右下；
   详情紧凑 `pp-details-sideslip`/106px/90%/按钮右上；展开详情 `pp-drawer-details`/120px/90%。
   面板宽度 2026-11-10 起统一 90%（原 45% 两列太挤，用户要求改）。
3. **列表统一用多维表格**（`showType=dimension`），数据来自数据集，
   数据集类型**建议选物理表而非业务对象**。
4. **条件专用表单**是解决「弱关联导致字段只能当文本框」的正解：
   ID → 下拉框或关联数据；时间 → 日期控件；人员 → 选择器-人员。
5. **导入表单禁止出现**创建人/创建时间/更新人/更新时间/ID/版本/流程实例，
   且必填字段必须和新建表单一致。
