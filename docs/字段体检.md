# 字段体检：疑似重复与冲突

> 入口：出包页第 2 个页签「字段体检」；多 sheet 上传时的提示走 AI 预览页的 notices。
> 代码：`pp6kit/fieldcheck.py`（判定）、`pp6kit/ai_sheet.cross_sheet_dupes`（跨 sheet）。
> 整理日期：2026-10-31。

解决的问题：一份需求表被拆成多个对象/表单后，经常出现**同一个东西写成两处**
（立项申请单位 / 立项申报单位）、**同一个名字配了不同东西**（一处文本一处下拉）、
**同一个字段候选值不一样**（一边 5 项一边 7 项）。这些在导入系统后才会暴露，
那时已经建了两个字段、两份数据。

## 五类检查

| 类别 | 判据 | 输出级别 |
|---|---|---|
| `near-name` 名字很像 | 相似度 ≥ 80% | 疑似 |
| | 相似度 ≥ 72% 且名字 ≥ 5 字 | 提示 |
| `name-type` 同名不同类型 | 同一中文名，跨对象 `type_new` 不一致 | 疑似 |
| `code-type` 同字段不同类型 | 同一 `code`，跨对象 `type_new` 不一致 | 疑似 |
| `option` 候选值不一致 | 同一名字/编码，`choices` 集合不同 | 疑似 |
| `form-type` 控件类型不一致 | 同一 `code` 在新建/详情/条件表单里 `field_type` 不同 | 疑似 |

名字/编码同时撞的只报一条（优先按中文名报，用户不用先翻译编码）。

## 误报是怎么压下去的

相似度算法单独用会把该共存的字段也刷出来，所以加了两道闸：

1. **三个字的短名不参与**。中文短词差一个字往往是不同概念。
2. **子序列 + 长度差 ≥ 2 → 跳过**。
   「项目来源」是「项目资金来源」的子序列（项目…来源，跳过「资金」），
   相似度 80%，但它们本来就该同时存在，跳过。
   而「立项申请单位 / 立项申报单位」不是子序列（「请」不在后者里），保留。

实测：真实的「项目立项业务对象」导出包（82 字段）跑出来 **0 条**；
「项目名称 / 项目简称」「金额 / 总金额」都不报；
「立项申请单位 / 立项申报单位」报，且附带候选值差异
（「立项申请单位」多「事业部」）。

阈值和判据只写在 `fieldcheck.near_level` 一处，界面提示和跨 sheet 比对共用，
不会出现「页签说不像、上传提示说像」。

## 多 sheet 上传

app 一次只分析一张 sheet（一张文件可能二三十张表单，全塞给模型不现实），
所以跨 sheet 的重复在最终对象里看不出来。因此在**读表阶段**（还没调模型、
2 ms 左右）先比一遍，命中就写进预览页的提示：

```
这个文件里多张表的字段很像，可能是同一个字段起了两个名字：
「立项申请表」立项申请单位 ↔ 「立项审批表」立项申报单位。
如果确实是同一个，建议先统一再分析，否则会建成两个字段
```

标准模板的配置表（`1_业务对象` / `2_字段` …）列名天然重复，按 `spec.SHEET_ORDER`
精确跳过，不会产生噪音（实测 0 条）。

## 边界

- **只提示，不自动改**。两个名字是不是同一件东西只有业务能判断，
  自动合并会把「确实要区分」的字段搞坏。
- 不影响出包，不占用校验错误数，角标用黄色不用红色。
- 不检查「表单控件引用了不存在的字段」——那条 `validate` 已经报，
  在「校验结果」页签里。
